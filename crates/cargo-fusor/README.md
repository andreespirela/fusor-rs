# cargo-fusor

Runs the fusor CLI as a Cargo subcommand, so `cargo fusor build` does the same
as `fusor build`. It has no commands of its own.

```sh
cargo install cargo-fusor
```

Most people want the standalone `fusor` command instead, from
[`fusor-cli`](https://crates.io/crates/fusor-cli).
