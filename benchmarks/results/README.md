# Benchmark history

[index.json](index.json) lists every record and identifies the published raw report.
Each `history/<id>/record.json` follows
[the experiment schema](../schemas/experiment.schema.json). It contains notes,
the publication selection, and a checksum for every evidence file. The `data/`
directory holds the raw JSON those checksums describe. Findings are `notes`
entries with a title, format and body; Markdown is supported inside JSON.
Reports and history pages are generated by shared tooling.

Use the commands in [the benchmark guide](../README.md). Never place executable
scripts, ad-hoc report generators, logs, binaries or profiles inside a record.
Scratch work belongs in `target/benchmarks/`; reusable commands belong in `tools/`.
The root ignore rules and `just bench verify` guard this boundary.
